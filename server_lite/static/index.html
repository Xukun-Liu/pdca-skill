产品介绍

riji-skill 是一个基于 PDCA 循环的协作框架，帮助你系统性地管理项目、积累知识、优化技能。

📋
7条铁律
Memory First / HARD-GATE / 无占位符 / 明确验收标准 / 多步任务用 TodoWrite / 测试先写 / 提交前自检
🔄
PDCA 流程
Plan → Do → Check → Act，每个任务都遵循完整闭环
🤖
多 Agent 协作
分工明确的子机器人：search、test、brainstorming、frontend-design 等
💾
记忆沉淀
每次对话自动沉淀到 memory，形成可复用的经验库
