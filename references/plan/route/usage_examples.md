## 示例3：简单任务——解释 Cookie 和 Session 的区别

```
用户：Cookie 和 Session 有什么区别？

AI：【判断：纯概念问答 → 直接回答，但读完memory再答】
用类比解释：
- Cookie = 电影院给你的纸质票根，你自己拿着，上面印了座位号。
  下次来可以出示，电影院就知道你是谁。
- Session = 电影院后台电脑里的存根，记录了你在哪排哪座、
  买了什么套餐。票根掉了也没事，后台还在。

核心区别：
| | Cookie | Session |
|---|--------|---------|
| 存在哪 | 用户浏览器里 | 服务器上 |
| 安全 | 不太安全（可被修改） | 安全 |
| 存活 | 可设长时效 | 关浏览器就没了 |
| 容量 | 很小（4KB） | 可以很大 |

能理解吗？需要我往深讲哪部分？

用户：懂了，谢谢

【写 memory：- [HH:MM] 解释 Cookie vs Session，用电影院票根类比】
```

## 简单 vs 复杂 速查

| | 简单 | 复杂 |
|---|------|------|
| 判断 | 一句话能说清 | 一句话说不清 |
| spec | 不需要 | 写 spec.md |
| task | 不需要 | 写 task.md |
| 追问/确认 | 一句话方案HARD-GATE确认 | 追到底，方案对比，分节确认 |
| 验收 | 当场确认 | 对照 spec 逐项 |
| memory | 一句话记录 | 全程记录 + 经验沉淀 |
