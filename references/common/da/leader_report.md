# 领导汇报文档（leader_report）

> 版本：v1.0.0 | 创建：2026-08-25
> 阶段标签：A.handoff

> 📖 **什么时候读这个文件**：用户要"给领导汇报 / 向上汇报 / 出汇报文档 / 给老板汇报 / 周报月报"等对上汇报材料时。
> 🔴 **不要在这时候读**：验收报告/手绘速览（走 hand-drawn-report.md）；做汇报 PPT（走 html_ppt_creation.md）——两者可衔接本文件的六段结构作为内容底稿。

---

## 一、六段结构模板（固定骨架）

按此顺序生成，每段一个二级标题，缺数据的段写"暂无数据"**不编造**：

```markdown
# {项目/任务名} 汇报（{YYYY-MM-DD}）

## 1. 一句话结论
{30 字内：现在处于什么状态 + 最关键的一个数字或事实。领导只看这行也能懂。}

## 2. 进展
- {已完成的里程碑 1（含日期）}
- {已完成的里程碑 2（含日期）}
- {正在进行的（当前卡点标注 ⚠）}

## 3. 数据成果
| 指标 | 之前 | 现在 | 变化 |
|------|------|------|------|
| {可量化指标} | {基线} | {当前值} | {+/-%} |

## 4. 风险与问题
| 风险/问题 | 影响 | 应对 | 需要的支持 |
|-----------|------|------|------------|
| {风险描述} | {高/中/低} | {已做/计划} | {要领导拍板/协调的} |

## 5. 下一步计划
- {短期（1-2 周）：具体动作 + 预期产出}
- {中期（1 月）：方向}

## 6. 需要的支持
- {资源/决策/协调事项，明确到"需要谁做什么"}（无则写"暂无需支持"）
```

## 二、数据源映射表（素材从哪拉，全部有出处）

| 汇报段 | 数据源 | 拉取方式 |
|--------|--------|----------|
| 一句话结论 | TASK_STATE.md（Goal/Status）+ spec §1.3 成功指标 | 读 `docs_rj/memory_rj/TASK_STATE_{task}.md` |
| 进展 | task.md 打勾项 + memory 索引行（status 类） | grep `- [x]` 计数 + memory_main 按时间倒序 |
| 数据成果 | spec §5 AC 基线数字 + 测试报告 | 读 spec 验收标准表 + check_rj/ 报告 |
| 风险与问题 | task.md 阻塞项 + spec §9 风险表 | grep `阻塞`/读 §9 表 |
| 下一步计划 | TASK_STATE.md（Next/Watch List）+ handoff 待办 | 读 TASK_STATE + handoff_rj/ 最新交接 |
| 需要的支持 | 对话中用户提过的资源诉求 | 从本次任务 memory 互动复盘段提取 |

## 三、三级领导适配（同一份底稿，三种详略）

| 领导类型 | 详略策略 | 结构调整 |
|----------|----------|----------|
| 直属领导（懂细节） | 全六段完整呈现 | 数据表格保留全量行 |
| 大领导（只要结论） | 1/3/6 段为主，2/4/5 各压缩成 3 行内 | 表格只留最关键 2-3 行指标 |
| 跨部门领导（不懂背景） | 段前加半句背景铺垫 | 术语换大白话（对齐 SKILL.md 沟通偏好） |

## 四、生成流程（agent 执行五步）

1. **拉数据**：按 §二映射表逐段读源文件（读不到的段标"暂无数据"，禁止编造）
2. **填模板**：按 §一六段结构填内容（结论先行，30 字内）
3. **适配详略**：问用户"汇报对象是直属/大领导/跨部门？"按 §三调整
4. **手绘速览**：文档顶部按 hand-drawn-report.md 内联手绘 SVG 速览图（默认带图、单文件自包含）
5. **落盘交付**：存 `docs_rj/handoff_rj/{task}_report_YYYYMMDD_HHMM.md` + 完整绝对路径给用户

## 五、示例（节选）

```markdown
# pdca-skill v1.0.4 升级汇报（2026-08-25）

## 1. 一句话结论
三大痛点改造全部完成，226 项测试全绿，记忆检索效率从"翻大文件"提升为"按标签直达"。

## 2. 进展
- 08-25 记忆文件夹制落地（126 条全量迁移，对账零差异）
- 08-25 /act 互动复盘上线（用户判断沉淀进记忆）
- 08-25 汇报 reference 落地（本报告即首个产物）

## 3. 数据成果
| 指标 | 之前 | 现在 | 变化 |
|------|------|------|------|
| 测试通过数 | 218 | 226 | +8 |
| 记忆检索方式 | 单文件全文翻 | 6 标签文件夹 | 结构化 |
| 迁移数据丢失 | - | 0 条 | 对账 equal |
```
