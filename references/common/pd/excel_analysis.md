## 〇、先搞懂本质（决定怎么干）

用一组生活类比记住数据分析在干嘛，能少走 80% 的弯路：

| 概念 | 本质类比 | 对操作的含义 |
|------|----------|--------------|
| **Excel 表格** | 一本**数字化账本 / 智能表格** | 行=一条记录，列=一个指标；能排序、筛选、算账 |
| **数据分析** | 从账本里**找出规律和答案** | 不是"把表做漂亮"，是"回答一个具体问题" |
| **数据清洗** | 下厨前**备菜**（洗、切、去烂叶） | 跳过这步，后面全错；真实工作 80% 时间花在这 |
| **透视表** | 一台**自动分类汇总机** | 拖几下字段，几秒出"按地区×品类"的汇总 |
| **图表** | **用图讲故事** | 没人爱看数字墙，合适的图让结论一眼懂 |
| **函数公式** | 一个**不累的算账机器人** | 写一次，源数据一变自动重算（别手算硬塞） |

> ⚠️ 关键推论：分析前先想清楚"要回答什么问题"（见第一节），否则清洗、透视、画图都是白做。

## 一、分析前：先想清楚 3 个问题（Plan，最重要的一步）

类比：下厨前先想「吃啥 / 给谁吃 / 材料齐不齐」，别一上来就开火。

| 要想清的问题 | 为什么 | 反面例子 |
|--------------|--------|----------|
| **① 要解决什么问题？** | 决定洗什么、算什么、画什么 | "帮我分析下这表" ❌（没目标）；"哪个地区利润最高" ✅ |
| **② 给谁看、要什么结论？** | 决定图的类型、详略、口径 | 给老板看要结论先行；给同事看要可复现步骤 |
| **③ 数据从哪来、够不够、可信吗？** | 垃圾进垃圾出，源头错全错 | 没确认口径就开始算，算出"负销售额" |

> 一句话：**先把"问题"写成一句话验收标准**（配合 acceptance_criteria.md 的 Given/When/Then），再动手。这一步省 1 小时，后面省 1 天。

## 二、标准分析流程（脊柱式 7 步）

把网上公认的 `DATA → CLEAN → STRUCTURE → ANALYZE → VISUALIZE → VERIFY → REPORT` 工作流落成本地可照抄的步骤：

```
Excel 数据分析脊柱
│
├─ 1. 取数（DATA）       读 Excel/CSV，原样导入，先不动手改
├─ 2. 清洗（CLEAN）      去重 / 补缺失 / 统一格式 / 剔异常   ← 最费时
├─ 3. 结构化（STRUCTURE）转"表格(Ctrl+T)"、做成一维表
├─ 4. 分析（ANALYZE）    透视表 + 核心函数 + 描述统计
├─ 5. 可视化（VISUALIZE）按结论选图（见第五节）
├─ 6. 验证（VERIFY）     交叉核对 / 敏感性测试（见第六节）
└─ 7. 出报告（REPORT）   结论先行 + 图表 + 数据可追溯
```

> 每条原则：原数据**留一份别动**（备份），所有改动在新表/新列做，方便回溯。

## 三、数据清洗（最费时，80% 精力在这）

真实数据常脏：重复行、空值、日期乱写、数字存成文本、异常值。清洗清单：

| 脏数据 | 处理做法 | 工具/命令 |
|--------|----------|-----------|
| **重复行** | 删除重复项（保留首次） | Excel：数据→删除重复项；pandas：`df.drop_duplicates()` |
| **缺失值** | 填 `N/A` 或均值/中位数（别留空影响公式） | `df.fillna("N/A")`；Excel：定位空值→批量填 |
| **格式不统一** | 日期/数字/大小写统一一种 | 分列、TRIM、UPPER/LOWER；pandas `pd.to_datetime()` |
| **前后空格** | 去空格 | `=TRIM(A1)`；pandas `str.strip()` |
| **异常值** | 条件格式高亮（如负销售额）肉眼复核 | Excel：条件格式→突出显示规则 |
| **字段粘连** | "张三-销售部"拆成两列 | 分列（按分隔符）；pandas `str.split()` |
| **智能填充** | 从"张明 1381234"抽手机号 | Excel：`Ctrl+E` 快速填充；pandas 正则 |

**清洗检查清单（交付前必勾）**：
- [ ] 无重复行
- [ ] 无空白关键列（或已显式标 N/A）
- [ ] 日期/数字格式统一
- [ ] 异常值已复核（不是误删）
- [ ] 原数据备份未动

## 四、核心分析方法

### 4.1 描述统计（先看全貌）
```python
import pandas as pd
df = pd.read_excel("data.xlsx")
print(df.describe())          # 计数/均值/标准差/最小/四分位/最大 一网打尽
print(df.median(numeric_only=True))   # 中位数（不受极端值影响）
```
> 类比：体检报告——先看清"平均身高、最高最矮"，再深挖异常。

### 4.2 透视表思维（分组汇总的核心）
四要素：**行 / 列 / 值 / 筛选**。把"按地区×品类算销售额"变成拖拽：
- 行=地区，列=品类，值=求和(销售额)，筛选=某时间段
- 可下钻（双击汇总格看明细）
- pandas 等价：`df.pivot_table(index="地区", columns="品类", values="销售额", aggfunc="sum")`

### 4.3 核心函数（Excel 原生，够用 90% 场景）
| 函数 | 干什么 | 示例 |
|------|--------|------|
| `SUMIF` / `SUMIFS` | 按条件求和（单/多条件） | `=SUMIFS(销售额,地区,"华东",品类,"A")` |
| `COUNTIF` / `COUNTIFS` | 按条件计数 | `=COUNTIF(状态,"已完成")` |
| `AVERAGEIF` | 按条件平均 | `=AVERAGEIF(地区,"华北",利润)` |
| `VLOOKUP` / `XLOOKUP` | 跨表查值（XLOOKUP 更稳） | `=XLOOKUP(编号,表2!编号列,表2!名称列)` |
| `IF` | 条件分支 | `=IF(利润>0,"赚","亏")` |

> 公式铁律（来自 xlsx skill，违反必翻车）：**用公式别硬编码**；**公式必须重算**（openpyxl 写的是公式串不是值，交付前用 LibreOffice 重算）；**零公式错误**（扫 `#REF! #DIV/0!` 等）。详见 [office_processing.md](../../do/code/office_processing.md) 第四节。

### 4.4 相关性初探
- 两指标是否同涨同跌？画**散点图**肉眼看；或用 `df.corr()` 看相关系数（-1~1，越靠±1 越强）。

## 五、图表选型（用什么图说事）

选错图 = 故事讲歪。一张表记住：

| 你想表达什么 | 用这个图 | 反例 |
|--------------|----------|------|
| **趋势**（随时间变化） | 折线图 | 别用饼图 |
| **构成 / 占比** | 饼图 / 堆叠柱图 | 类别>5 用柱图别用饼 |
| **对比**（谁多谁少） | 柱形图 / 条形图 | 别用折线 |
| **分布**（集中哪） | 直方图 | — |
| **关系**（两变量相关） | 散点图 | — |
| **KPI 组合** | 组合图（柱+线） | — |

**去 chart junk（图表垃圾）**：别加多余阴影/立体/网格线；标题说清结论（"华东利润最高"而非"利润图"）；配色有主有次。

## 六、简单预测（科普级，不堆公式）

| 方法 | 干什么 | 怎么做 |
|------|--------|--------|
| **移动平均** | 平滑波动看大势 | Excel：数据→数据分析→移动平均；pandas `df["值"].rolling(3).mean()` |
| **同比** | 今年 vs 去年同期 | `(本期-去年同期)/去年同期` |
| **环比** | 这月 vs 上月 | `(本月-上月)/上月` |
| **线性回归** | 看整体走势（谨慎用） | `pandas` + `scipy.stats.linregress`；**必须说明假设**（线性、历史可延续） |

> ⚠️ 预测只是"基于过去的合理猜测"，不是算命。给结论时必须附"前提假设"和"误差范围"，别把预测当承诺。

## 七、工具选型（Python 优先 vs Excel 原生）

| 场景 | 首选 | 原因 |
|------|------|------|
| 批量 / 大数据 / 要可复现 | **pandas**（Python） | 脚本一次写好，下次换数据重跑即可，不手点 |
| 读写带格式/公式的 Excel | **openpyxl** | 保留单元格样式与公式 |
| 交互式探索 / 给同事看 | **Excel 原生透视表** | 拖拽即时出结果，零代码 |
| 公式重算（必做） | **LibreOffice 无头** | `soffice --headless --calc --convert-to xlsx --recalculate` |
