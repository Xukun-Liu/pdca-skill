# pdca-skill v1.0.4 更新说明

> pdca-skill 是一套「协作框架 + 技能编排器」：自身不实现具体能力，只管跨任务硬规则（7 条铁律 / HARD-GATE / Memory First / 触发钩子路由）与按需加载的参考模块。它不是借来的工具，而是**协作宪法**。
>
> v1.0.4 在 v1.0.3 稳定发布版基础上，围绕「记忆更好用、复盘更闭环、汇报更省心、数据更能打、发布更放心」五个方向做了体系化升级。

---

## 一、本版亮点（TL;DR）

1. **记忆文件夹制**：记忆不再是一整篇大文档，而是按 6 大分类 + 「标签/年月」两层文件夹归档，主索引一行直达正文，找经验像翻快递柜一样准。
2. **/act 互动复盘**：收尾时动态问 2-3 个问题（学到什么教训、做了什么决策、下一步怎么走），回答自动并入本次记忆，闭环不丢。
3. **领导汇报模板**：新增 `leader_report.md` 六段结构（结论→进展→数据→风险→计划→求助），配数据源映射与三级领导适配，触发词精确路由不误触发。
4. **数据全流程方法论**：Excel 分析升级为「数据处理全流程」，融入 12 项防错机制，核心命题——**AI 数据分析最致命的缺陷是「算错了但不报错」**。
5. **导师型人格对齐**：引入层改为「让你敢做什么」的宣言式表达，新增「你相信什么」信条节（7 条铁律各配存在理由与引导问），硬规则零改动。
6. **发布质量兜底**：打包前逐文件嗅探校验、版本号一处改五处自动联动、用户数据零泄漏规则、Windows 编码乱码根治。
7. **文档回到项目**：项目文档默认建在项目根目录（`./docs_rj`），跟项目走、随仓库搬，不再散落到用户主目录。

---

## 二、详细变更

### 1. 记忆体系：文件夹制 + 主索引（三痛点之一）

- **6 大记忆分类**：`tech_solution`（技术方案）/ `pitfall`（踩坑）/ `workflow`（工作流）/ `tool_usage`（工具用法）/ `decision`（决策）/ `status`（状态）。
- **两层文件夹归档**：`{分类}/{年月}/` 深层结构，`memory_main.md` 主索引「一行一条、直达正文」。
- **自动迁移工具**：`migrate_memory_v104.py` 全量迁移旧扁平记忆，迁移前后逐条对账（条数一致、内容一致），双备份 + `schema_version` 防新旧格式混写。
- **容量口径更新**：「一条」= 一条索引行，容量告警在索引化后依然有效。

### 2. /act 互动复盘（三痛点之二）

- 收尾阶段动态提出 **2-3 个复盘问题**（教训 / 决策 / 下一步），不是死板问卷。
- 回答**自动并入同一次记忆写入**，不需要再单独补记。
- 用户跳过问题时有明确的 SKIPPED 语义留痕；无人值守（/loop auto）模式自动跳过并记录。

### 3. 领导汇报（三痛点之三）

- 新增 `references/common/da/leader_report.md`：**六段结构**（结论 → 进展 → 数据 → 风险 → 计划 → 求助）。
- 配「数据源映射表」：每一段写什么、从哪取数，一目了然。
- **三级领导适配**：高层看结论与风险、中层看进展与计划、执行者看细节与求助。
- 触发钩子升级到 v1.1.8，关键词精确路由（禁止裸「汇报」一词三重误触发），SKILL.md 增加仲裁规则。

### 4. 数据能力：Excel → 数据全流程方法论

- `excel_analysis.md` 升级为 `data_analysis.md`（v2.0.0），从「Excel 分析」扩展为「数据全流程方法论」。
- 融入 **12 项防错机制**：结构体检三问、对账四道、独立质控七问、Twyman's Law 五问排查、抗差统计、图表感知精度阶梯、洞察三层、探索 vs 推断红线、口径哲学、七条红线等。
- 全库 8 处引用同步改名，死引用清零。

### 5. SKILL.md 导师型改造

- 引入层从「是什么」改为「**让你敢做什么**」的身份宣言式重写。
- 三定位重新表达（记忆 / PDCA / docs 三位一体闭环）。
- 新增「**你相信什么**」信条节：7 条铁律各配「存在理由 + 引导问」，帮助理解而非死记（遵循 Chesterton's Fence，不推翻任何现有规则）。
- Agent 人格对齐 Coaching Style（严谨不谄媚的专家导师）。

### 6. 发布包质量兜底（实机打包测试驱动）

- **用户数据零泄漏**：打包排除规则补齐，外置用户数据目录绝不会被打进发布包。
- **编码根治**：子进程强制 UTF-8（`PYTHONUTF8=1`），修复 Windows 中文环境 GBK 乱码。
- **版本联动**：`bump_version` 一处改、四处版本号自动更新；`validate_skill.py` 五方探针校验 SKILL.md / HISTORY / evals / red_flags 版本一致性。
- **包内容嗅探**：`_verify_package` 逐文件校验包完整性，README / CHANGELOG 缺失时自动骨架模板化生成。
- **仓库防错位**：git toplevel 校验防嵌套仓库打包错位，测试隔离外层仓库干扰。
- 新增「同步到 skill」三段式仲裁规则，以及第 20 条红旗「目检不附客观证据 = Verifier Theater」。

### 7. 文档落点：回到项目根目录

- v1.0.0 曾把文档外置到用户主目录，与「文档跟项目走」的直觉相反。v1.0.4 起，**项目文档默认建在项目根 `./docs_rj`**（写入落点、启动守卫、强制同步、文档合并共 6 处统一）。
- **老用户平滑兼容**：检测到外置目录有真实历史文档时，按「只读存档」处理——旧数据原地保留可读、不迁移、不续写，新文档一律进项目，防止同一任务的方案和记忆撕裂两处。
- **/plan 默认轻量**：方案/任务模板大幅瘦身（spec 370→、task 242→ 行量级精简），简单任务不再被重型模板淹没，复杂任务仍可走全套。

## 三、质量与验证

- **测试**：全量回归通过（v1.0.4 高峰期 279 项全绿；本版收尾验证保持通过）。
- **静态校验**：`validate_skill.py` 33/33 PASS，0 MUST FIX。
- **对抗审查**：三痛点改造经独立 subagent 4H/7M/4L 审查全部修复回填（含 distill/learn 经验闭环、下游深层扫描适配、memory_class 接口、汇报仲裁等高危项）。
- **发布前实测**：打包质量修复全部由实机打包测试驱动，而非纸面推演。

---

## 四、升级说明

- **用户数据安全**：v1.0.4 延续「用户数据外置」机制（`~/.pdca-skill/data/`），升级 skill 包（解压覆盖）时个人记忆与数据 **0 丢失**。
- **记忆迁移**：首次启动新版会自动把旧扁平记忆迁移到文件夹制（迁移前后自动对账 + 双备份），也可手动运行 `migrate_memory_v104.py`（先 `--dry-run` 预览）。
- **老文档处理**：外置 `docs_rj` 若有历史文档，新版按只读存档保留，新文档写入项目根；如需搬回，手动移动后用 `--declare-primary` 宣告主目录。
- **无破坏性改动**：7 条铁律与核心硬规则保持不变，老用法全部兼容。
